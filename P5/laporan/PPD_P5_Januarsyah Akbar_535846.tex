\chapter[Tujuan Praktikum]{Tujuan Praktikum}
Tujuan pelaksanaan praktikum pada Pertemuan V adalah sebagai berikut:
\begin{enumerate}
    \item Mahasiswa dapat menerapkan metode peramalan (\textit{forecasting}) berbasis algoritma \textit{machine learning}, meliputi Multilayer Perceptron (MLP/Neural Network), K-Nearest Neighbors (KNN), Decision Tree, dan Random Forest, untuk memprediksi nilai periode berikutnya berdasarkan data historis deret waktu.
    \item Mahasiswa dapat memahami dan mengimplementasikan teknik pembentukan pasangan data deret waktu menggunakan metode jendela geser (\textit{sliding window}) serta menambahkan rekayasa fitur statistik (\textit{feature engineering}) pada setiap jendela pengamatan.
    \item Mahasiswa dapat melakukan analisis dan komparasi performa model menggunakan metrik evaluasi Root Mean Squared Error (RMSE) dan Koefisien Korelasi Pearson (\textit{Pearson Correlation Coefficient}).
    \item Mahasiswa dapat membandingkan efektivitas pemodelan deret waktu satu variabel (\textit{univariate}) dan multi-variabel (\textit{multivariate}) pada kasus peramalan harga saham Tesla (TSLA) untuk horizon dua hari ke depan.
    \item Mahasiswa dapat menganalisis perbedaan mendasar kapasitas generalisasi dan ekstrapolasi nilai antaralgoritma dalam menangkap tren pergerakan data riil.
\end{enumerate}

\chapter{Dasar Teori}

\section{Supervised Learning}
\textit{Supervised learning} merupakan paradigma pembelajaran mesin di mana model dilatih menggunakan himpunan data berlabel (\textit{labeled dataset}) \cite{ref_retno}. Setiap baris observasi terdiri atas pasangan fitur masukan ($X$) dan nilai target luaran ($y$). Selama fase pelatihan, model menyesuaikan parameter internalnya agar fungsi pemetaan matematis $f(X) \approx y$ mampu menghasilkan galat estimasi sekecil mungkin. Pola hubungan yang terbentuk selanjutnya menjadi acuan dalam memprediksi data baru yang belum pernah dilihat sebelumnya \cite{ref_santoso}. Pada ranah regresi dan peramalan, nilai target $y$ bertipe numerik kontinu.

\section{Forecasting dan Karakteristik Data Time Series}
Peramalan (\textit{forecasting}) adalah proses memproyeksikan besaran nilai pada periode mendatang dengan menguji dan memodelkan pola historis masa lalu \cite{ref_vimala}. Berbeda dari data tabular statis, data deret waktu (\textit{time series}) terikat kuat oleh urutan kronologis. Observasi pada waktu $t$ memiliki autokorelasi dengan observasi pada langkah waktu terdahulu ($t-1, t-2, \dots$). Pemisahan data latih dan data uji pada kasus deret waktu wajib mempertahankan urutan waktu tanpa proses pengacakan (\textit{shuffle=False}) guna mencegah terjadinya kebocoran informasi masa depan (\textit{data leakage}).

\section{Metode Sliding Window}
Algoritma pembelajaran mesin konvensional memerlukan representasi matriks fitur dua dimensi. Metode \textit{sliding window} (jendela geser) mentransformasikan deret sekuensial menjadi kumpulan sampel tabular \cite{ref_han}. Jendela sepanjang $n_{in}$ langkah waktu digeser langkah demi langkah sepanjang barisan data untuk membentuk fitur prediktor, sedangkan nilai pada langkah ke-($n_{in} + n_{out}$) ditetapkan sebagai label sasaran. Jika model dirancang untuk memprediksi target satu langkah ke depan, maka $n_{out} = 1$. Sebaliknya, jika target berada pada dua periode mendatang, maka digunakan parameter $n_{out} = 2$.

\section{Rekayasa Fitur Statistik pada Deret Waktu}
Guna memperkaya konteks distribusi nilai di dalam setiap jendela pengamatan, dilakukan penambahan fitur statistik (\textit{statistical feature engineering}). Sebanyak delapan besaran statistik deskriptif diekstraksi dari setiap larik sampel input:
\begin{enumerate}
    \item Nilai minimum ($\min$) dan maksimum ($\max$).
    \item Selisih rentang nilai ($\text{range} = \max - \min$).
    \item Standar deviasi ($\sigma$) untuk mengukur dispersi nilai terhadap titik pusat.
    \item Rata-rata hitung ($\mu$) dan median (kuartil tengah) untuk mengidentifikasi tendensi sentral.
    \item Kurtosis untuk mengukur derajat keruncingan ekor distribusi data.
    \item Skewness (kemiringan) untuk mengetahui asimetri sebaran data terhadap rata-rata.
\end{enumerate}
Penambahan atribut ini menyediakan ringkasan bentuk distribusi lokal kepada model sehingga model tidak hanya membaca urutan angka mentah, melainkan juga menangkap dinamika volatilitas deret waktu.

\section{Algoritma Machine Learning untuk Forecasting}
Empat algoritma regresi dan pembelajaran mesin diterapkan dalam percobaan ini:

\begin{enumerate}
    \item \textbf{Multilayer Perceptron (MLP Regressor)}: \\
    MLP merupakan jaringan syaraf tiruan (\textit{feedforward neural network}) yang tersusun atas lapisan masukan (\textit{input layer}), satu atau lebih lapisan tersembunyi (\textit{hidden layers}), dan lapisan luaran (\textit{output layer}) \cite{ref_russell}. Setiap neuron memproses kombinasi linear dari bobot masukan yang kemudian ditransformasikan oleh fungsi aktivasi non-linear, seperti \textit{Rectified Linear Unit} (ReLU):
    \begin{equation}
        f(z) = \max(0, z)
    \end{equation}
    Optimalisasi bobot dilakukan secara iteratif menggunakan algoritma propagasi balik (\textit{backpropagation}) berbasis gradien. Keunggulan utama MLP terletak pada kapasitasnya memodelkan fungsi kontinu non-linear serta kemampuannya melakukan ekstrapolasi tren data di luar rentang nilai pelatihan.

    \item \textbf{K-Nearest Neighbors (KNN Regressor)}: \\
    KNN merupakan algoritma regresi berbasis memori (\textit{instance-based learning}) tanpa pembentukan model parametrik secara eksplisit \cite{ref_pedregosa}. Prediksi diperoleh dengan mencari $k$ sampel terdekat di dalam ruang fitur berdasarkan metrik jarak Euclidean:
    \begin{equation}
        d(x, x') = \sqrt{\sum_{j=1}^p (x_j - x'_j)^2}
    \end{equation}
    Nilai estimasi target merupakan rata-rata sederhana dari nilai target milik $k$ tetangga terdekat tersebut. Model ini rentan mengalami degradasi performa ketika berhadapan dengan dimensi fitur yang tinggi serta tidak dapat memprediksi nilai di luar batas ekstrem data latih.

    \item \textbf{Decision Tree Regressor}: \\
    Pohon keputusan mempartisi ruang fitur secara hierarkis menjadi wilayah-wilayah ortogonal yang lebih homogen menggunakan pemisahan biner rekursif (\textit{recursive binary splitting}) \cite{ref_han}. Titik pemisahan simpul ditentukan berdasarkan reduksi galat variansi terkecil, lazimnya diukur dengan kriteria \textit{Mean Squared Error} (MSE). Estimasi akhir pada simpul daun (\textit{leaf node}) dihitung sebagai rata-rata dari target observasi yang terperangkap pada daun tersebut.

    \item \textbf{Random Forest Regressor}: \\
    Random Forest merupakan metode ansambel (\textit{ensemble learning}) yang menggabungkan keluaran dari ratusan pohon keputusan independen yang dibangun melalui teknik \textit{bootstrap aggregating} (\textit{bagging}) dan seleksi subset fitur acak \cite{ref_pedregosa}. Agregasi rata-rata prediksi dari seluruh pohon terbukti efektif meredam varians galat acak tanpa menambah bias model, menghasilkan estimasi yang jauh lebih stabil dibanding pohon tunggal:
    \begin{equation}
        \hat{y} = \frac{1}{B}\sum_{b=1}^B T_b(x)
    \end{equation}
\end{enumerate}

\section{Metrik Evaluasi Performa Model}
Kualitas dan ketepatan estimasi model peramalan dievaluasi menggunakan dua metrik statistik utama:

\begin{enumerate}
    \item \textbf{Root Mean Squared Error (RMSE)}: \\
    RMSE mengukur akar kuadrat dari rata-rata kuadrat deviasi antara nilai riil ($y_i$) dan nilai estimasi model ($\hat{y}_i$) \cite{ref_chai}:
    \begin{equation}
        \text{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2}
    \end{equation}
    Karena nilai selisih dikuadratkan sebelum ditarik akar, RMSE memberikan bobot penalti yang sangat tegas terhadap galat berukuran besar. Nilai RMSE yang semakin mendekati angka nol mengindikasikan tingkat akurasi model yang semakin presisi.

    \item \textbf{Koefisien Korelasi Pearson ($R$)}: \\
    Koefisien korelasi Pearson mengukur kekuatan dan arah hubungan linear antara barisan target aktual dengan hasil peramalan model \cite{ref_benesty}:
    \begin{equation}
        R = \frac{\sum_{i=1}^n (y_i - \bar{y})(\hat{y}_i - \bar{\hat{y}})}{\sqrt{\sum_{i=1}^n (y_i - \bar{y})^2 \sum_{i=1}^n (\hat{y}_i - \bar{\hat{y}})^2}}
    \end{equation}
    Nilai $R$ berada pada rentang $-1$ hingga $+1$. Dalam konteks peramalan, nilai $R$ positif yang mendekati $+1$ membuktikan bahwa keluaran model berhasil menangkap pola fluktuasi data riil secara konsisten.
\end{enumerate}

\subsection{Formulasi Sliding Window dan Rekayasa Fitur Statistik}
Fungsi \textit{sliding window} dibentuk melalui fungsi \texttt{split\_sequences} dengan ukuran jendela masuk 7 hari ($n_{in} = 7$) dan langkah keluar 1 hari ($n_{out} = 1$). Artinya, nilai peminjaman sepeda selama 7 hari berturut-turut digunakan untuk mengestimasi peminjaman sepeda pada hari ke-8.

\begin{lstlisting}[style=pythonstyle, caption=Definisi Fungsi Sliding Window dan Ekstraksi Fitur Statistik]
def split_sequences(sequences, n_steps_in, n_steps_out):
    X, y = list(), list()
    for i in range(len(sequences)):
        end_ix = i + n_steps_in
        out_end_ix = end_ix + n_steps_out
        if out_end_ix > len(sequences):
            break
        seq_x, seq_y = sequences[i:end_ix, :-1], sequences[out_end_ix - 1, -1]
        X.append(seq_x)
        y.append(seq_y)
    return array(X), array(y)

def stats_features(input_data):
    inp = list()
    for i in range(len(input_data)):
        inp2 = list(input_data[i])
        min_v = float(np.min(inp2))
        max_v = float(np.max(inp2))
        diff = (max_v - min_v)
        std = float(np.std(inp2))
        mean = float(np.mean(inp2))
        median = float(np.median(inp2))
        kurt = float(kurtosis(inp2))
        sk = float(skew(inp2))
        inp2.extend([min_v, max_v, diff, std, mean, median, kurt, sk])
        inp.append(inp2)
    return np.array(inp)
\end{lstlisting}

\subsection{Analisis Fenomena Ekstrapolasi: Mengapa MLP Jauh Mengungguli Tree Models?}
Perbedaan kontras performa antara MLP dan model pohon keputusan pada dataset saham Tesla merupakan konsekuensi teoretis dari mekanisme inferensi masing-masing algoritma \cite{ref_russell, ref_pedregosa}. Fenomena ini dianalisis secara visual pada Gambar \ref{fig:tsla_extrapolation_analysis} yang menyoroti 100 sampel data uji terakhir ketika harga saham Tesla melonjak drastis dari 350 USD hingga menyentuh 780 USD.

\screenshotimage{gambar/tsla_extrapolation_analysis.png}{Analisis Fenomena Ekstrapolasi pada 100 Sampel Data Uji Terakhir Saham Tesla}{tsla_extrapolation_analysis}

Alasan teknis di balik fenomena ini dirinci sebagai berikut:

\begin{enumerate}
    \item \textbf{Ketidakmampuan Model Berbasis Pohon Melakukan Ekstrapolasi (\textit{Plateau Effect})}: \\
    Decision Tree dan Random Forest membagi ruang fitur menjadi wilayah-wilayah hiperkotak (\textit{hyper-rectangles}). Nilai prediksi untuk wilayah daun tertentu adalah nilai konstan berupa rata-rata target observasi latih yang masuk ke daun tersebut. Akibatnya, model pohon keputusan secara teoritis \textbf{tidak akan pernah mampu menghasilkan prediksi yang lebih besar daripada nilai target maksimum di data latih}. Ketika harga saham Tesla menembus level 400 hingga 780 USD pada data uji, Decision Tree dan Random Forest mengalami kejenuhan dan mendatar (\textit{plateau}) pada rentang 350 sampai 380 USD. Hal serupa terjadi pada KNN, di mana tetangga terdekat yang ditemukan selalu terbatas pada titik-titik data latih terdahulu.

    \item \textbf{Kapasitas Pemetaan Tren Non-Linear Kontinu pada MLP}: \\
    Sebaliknya, Multilayer Perceptron memodelkan target sebagai fungsi kontinu melalui kombinasi matriks bobot dan fungsi aktivasi ReLU. Komposisi lapisan tersembunyi mampu menangkap laju perubahan (\textit{slope}) dan kemiringan tren pertumbuhan harga. Ketika fitur masukan menunjukkan kenaikan sekuensial yang konsisten, jaringan syaraf tiruan mampu mengekstrapolasikan nilai keluaran ke domain angka yang belum pernah ada pada masa pelatihan, sehingga kurva prediksi MLP dapat terus menanjak mengikuti lonjakan riil harga saham Tesla hingga level 780 USD.
\end{enumerate}

\subsection{Penentuan Model Terbaik}
Berdasarkan seluruh pengujian numerik dan visualisasi, model \textbf{Multilayer Perceptron (MLP) dengan konfigurasi masukan Multivariate (Close + Open 7 hari)} dinobatkan sebagai model forecasting terbaik. Model ini berhasil menekan galat rata-rata hingga \textbf{18.27 USD} serta mempertahankan tingkat korelasi sebesar \textbf{0.9708}.

\chapter{Kesimpulan}

Praktikum modul peramalan (\textit{forecasting}) ini membuktikan bahwa metode pembelajaran mesin mampu diterapkan secara efektif untuk memproyeksikan data deret waktu sekuensial pada kasus peramalan permintaan peminjaman sepeda (\textit{Bike Sharing}) maupun proyeksi harga saham pasar modal (\textit{Tesla Stock Price}). Urutan kronologis data deret waktu menuntut pembagian data latih dan data uji tanpa proses pengacakan (\textit{shuffle=False}) guna menjamin validitas evaluasi. Penerapan teknik jendela geser (\textit{sliding window}) berhasil mengonversi deret satu dimensi menjadi matriks masukan terstruktur, sedangkan penambahan delapan ringkasan fitur statistik deskriptif memperkaya konteks representasi volatilitas lokal.

Hasil eksperimen pada dataset Bike Sharing memperlihatkan keunggulan model Multilayer Perceptron (MLP) dengan perolehan RMSE terendah sebesar 1243.150 dan koefisien korelasi Pearson tertinggi sebesar 0.751, diikuti oleh Random Forest (RMSE 1324.452). Sementara itu, implementasi pada kasus saham Tesla mengonfirmasi dua temuan penting:
\begin{enumerate}
    \item Pendekatan \textit{multivariate} yang menggabungkan riwayat harga penutupan (\texttt{Close}) dan harga pembukaan (\texttt{Open}) selama 7 hari sebelumnya terbukti lebih unggul dibanding pendekatan \textit{univariate}. Penambahan fitur harga pembukaan secara konsisten memangkas nilai galat RMSE pada seluruh algoritma pengujian.
    \item Multilayer Perceptron (MLP) terbukti menjadi model terbaik secara mutlak dengan nilai RMSE sebesar 18.27 USD dan korelasi Pearson mencapai 0.9708 pada skenario \textit{multivariate}. Keunggulan ini dipicu oleh kemampuan intrinsik arsitektur jaringan syaraf tiruan dalam mengekstrapolasikan tren pertumbuhan harga non-linear ke wilayah nilai baru, melampaui keterbatasan algoritma berbasis pohon keputusan (Decision Tree dan Random Forest) yang mengalami saturasi batas atas saat menghadapi reli lonjakan harga saham.
\end{enumerate}
